# Toby's Adventure

Toby's Adventure is a Minecraft plugin designed to enhance player experiences with engaging adventures and custom commands. This plugin introduces a unique adventure system that allows players to embark on exciting quests, complete challenges, and earn rewards. It also includes custom commands to interact with the adventure system and other players.

## Install

1. Download the plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to load the plugin.

## Use

1. Join the Minecraft server where the plugin is installed.
2. Use the `/ciao` command to greet the server and start your adventure.
